# ReviewerBot Realize — Telegram Mini App

Мини-приложение для сбора отзывов о чае/сервисе/доставке и публикации их в Telegram-канале. Пользователь оставляет отзыв в WebApp, отзыв сохраняется в SQLite и отправляется в канал в структурированном виде: краткое резюме + отдельное сообщение с текстом отзыва.

## Возможности

- WebApp-форма с категориями (чай/сервис/доставка), рейтингом, мультивыбором «что понравилось/не понравилось», текстом отзыва и фотографией (для чая — обязательно).
- История отзывов в WebApp.
- Отправка в Telegram-канал:
  - **Короткое резюме** (caption к фото или отдельное сообщение без фото).
  - **Текст отзыва** отправляется отдельным сообщением.
- Работа в браузере и в Telegram Mini App.

## Структура проекта

- `index.html` — фронтенд WebApp (форма отзывов, история, UI/UX).
- `main.py` — Telegram-бот + HTTP backend (`aiohttp`).
- `reviews.db` — SQLite база.
- `promo.json` — промо-текст/код после успешной отправки.

## Быстрый старт

1. Установите зависимости:

```bash
pip install -r requirements.txt
```

2. Укажите переменные окружения **или** заполните `bot_config.json`:

- `BOT_TOKEN` / `TELEGRAM_BOT_TOKEN`
- `CHANNEL_ID` / `TELEGRAM_CHANNEL_ID` / `BOT_CHANNEL_ID`

Опционально:

- `WEBAPP_HOST` (по умолчанию `0.0.0.0`)
- `WEBAPP_PORT` (по умолчанию `8080`)
- `WEBAPP_URL` (по умолчанию `http://<host>:<port>/webapp`)
- `RB_REVIEWS_DB` — путь к SQLite базе

3. Запуск:

```bash
python main.py
```

4. Откройте WebApp:

- В браузере: `http://<host>:<port>/webapp`
- В Telegram: команда `/start` отправит кнопку «Оставить отзыв».

## Backend API

### `POST /api/review`

- `multipart/form-data`
- Поля:
  - `payload` — JSON с данными отзыва.
  - `photo` — файл изображения (обязательно для категории `tea`).

### `GET /api/reviews`

Параметры:

- `offset` (по умолчанию `0`)
- `limit` (по умолчанию `10`, максимум `50`)
- `user_id` (опционально)

Ответ:

```json
{
  "items": [
    {
      "id": 1,
      "created_at": "2024-01-01T12:00:00Z",
      "category": "tea",
      "rating": 5,
      "display_name": "Анна",
      "tea_title": "Шу Пуэр",
      "liked_most": "ВКУС",
      "text": "Очень вкусно"
    }
  ],
  "hasMore": false
}
```

## Формат сообщений в канале

Отзыв отправляется в канал в **двух сообщениях**:

1. **Краткое резюме** (caption к фото или отдельное сообщение):

```
📝 Новый отзыв

Опубликовано: @username
Категория: Чай
Чай: Шу Пуэр
Рейтинг: ⭐⭐⭐⭐⭐
Лучшие моменты: ВКУС, АРОМАТ
Не понравилось: ПОСЛЕВКУСИЕ

#отзыв #отзыв_чай
```

2. **Текст отзыва** отдельным сообщением:

```
💬 Отзыв:
Очень понравился вкус, буду брать ещё.
```

Это упрощает модерацию и делает ленту канала более читаемой.

Если резюме длиннее 1024 символов, оно отправляется отдельным сообщением, затем сразу идёт текст отзыва, а фото (если есть) отправляется отдельным сообщением без подписи.

## Заметки

- Фото обязательно для категории `tea`.
- Максимальный размер фото: 8 MB.
- Сообщения в канал автоматически режутся по лимитам Telegram.
